# 학급 자리배치

번호만으로 학급 자리를 배치하는 웹앱입니다. 설치나 서버 없이 `index.html` 하나로 동작합니다.

## 기능

- 번호 무작위 섞기 (섞는 중 애니메이션)
- 번호 두 칸을 차례로 누르거나 끌어서 자리 바꾸기, 빈 자리로 옮기기
- 자리 고정(자물쇠): 고정한 자리는 섞어도 그대로 유지
- 되돌리기, 번호순으로 되돌리기
- 학생 수(1~40명), 한 줄 자리 수(2~8자리), 짝꿍끼리 붙이기 설정
- 교탁에서 바라본 모습(180° 회전) 보기
- 배치도를 글자로 복사
- 마지막 배치를 브라우저에 자동 저장 (localStorage)
- 모바일 터치, 키보드 조작, 다크 모드 지원

기본값은 11명, 4자리씩 3줄입니다.

## 사용하기

`index.html`을 브라우저로 열면 바로 실행됩니다.

## GitHub Pages로 공개하기

1. 저장소의 **Settings → Pages**로 이동합니다.
2. Source를 **Deploy from a branch**로 선택합니다.
3. Branch는 `main`, 폴더는 `/ (root)`로 정하고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://사용자이름.github.io/저장소이름/`에서 열립니다.

## 참고

- 글꼴(Do Hyeon, IBM Plex Sans KR)은 Google Fonts에서 불러오며, 불러오지 못하면 기본 글꼴로 표시됩니다.
- 학생 이름이나 개인정보는 저장하지 않고 번호만 사용합니다.
